# 房間校正與燈光

目前使用場景：`Assets/CompanionRoom/Scenes/CompanionRoom.unity`。

原配置已先保存，備份位置記錄於 `Artifacts/RoomPolish/snapshot.json` 的 `backup` 欄位，該資料夾內的 `CompanionRoom.unity` 是調整前版本。原模型 FBX、來源 Blender 檔與原貼圖均保留。

這次沿用使用者的配置，校正床、桌、椅、書櫃、地毯的支撐高度與靠牆間距，讓盆栽、塔羅牌及兔子貼合桌面或櫃面；靈擺稍微縮小以配合牆架深度。各項位移記錄在 `Artifacts/RoomPolish/adjustments.json`。

窗戶旁的原牆面已另建真正貫穿的拱形開口；原始房間 FBX 未覆寫。開洞後的場景網格、分離透明窗片的網格及相關材質位於 `Assets/CompanionRoom/Art/UserModels/Polished`。透明窗片關閉不透明投影，窗框仍可投影。窗外補光會隨房間主光亮度調整。

床頭兔兔壁燈綁定 `WallLampItem`，播放時點擊即可開關，沿用既有音效與開關狀態保存。發光材質保留原貼圖，因此兔兔臉部仍可辨識。

屋頂暖黃色裝飾使用獨立材質與 `SoftRoofGlow`，以小幅、緩慢的亮度變化呈現微光；牆面不會一起發光。主攝影機改為從房間開口朝內的正面斜俯視，並保留完整房間邊界。

播放驗證結果在 `Artifacts/RoomPolish/play_validation.txt`，內容包括窗洞射線、玻璃投影設定、點擊壁燈與開關效果及攝影機設定；預覽為同資料夾的 `Room_LampOn.png` 與 `Room_LampOff.png`。
