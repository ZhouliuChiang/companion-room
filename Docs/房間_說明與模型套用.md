# 兔兔房間：說明與模型套用規格

場景：`Assets/CompanionRoom/Scenes/CompanionRoom.unity`
程式：`Assets/CompanionRoom/Scripts/`（命名空間 `CompanionRoom`）

目前房間裡的家具都是**占位模型**（程式產生的圓角方塊）。互動、對話、光線、占卜、紀錄已經完成；正式模型只要照第 2 節放進去，不需要改程式。

---

## 1. 使用方式

### Unity 選單（Tools → 兔兔房間）

| 選單 | 作用 |
|---|---|
| 1. 建立範例場景 | 重新產生整個場景（占位家具、燈光、鏡頭、互動）。**會覆蓋場景檔**，換好正式模型之後就不要再按。 |
| 2. 輸出 Windows 版 | 輸出到 `Builds/CompanionRoom/CompanionRoom.exe`（1600×900 視窗）。 |
| 3. 拍攝預覽圖 | 早晨／夕陽／夜晚各拍一張到 `Docs/Preview/`。 |
| 4. 檢查場景 | 檢查每個物品的模型、點擊範圍、必要零件與資料檔，結果在 Console。 |

### 房間裡的互動

| 物品 | 點擊後 |
|---|---|
| 相片 | 開啟相簿（◀ ▶ 或 ← → 翻頁）。相框會顯示最後看的那張。 |
| 電腦 | 螢幕亮起 → 設定（音樂、音效、文字速度、顯示物品名稱、依現實時間決定光線、全螢幕、畫質、清除紀錄、結束陪伴）。 |
| 壁燈 | 開／關燈（會記住）。 |
| 窗戶 | 早晨 → 夕陽 → 夜晚 → 早晨，光線、窗外天空、陰影與色調一起轉換。 |
| 桌上塔羅 | 選擇「單張指引」或「過去・現在・未來」→ 可寫下問題 → 洗牌、發牌 → 逐張點擊翻牌 → 對話框解讀 → 自動存入紀錄。 |
| 櫃子 | 櫃門打開 → 占卜紀錄（左側清單、右側牌面與解讀，可刪除單筆）。 |

- 滑鼠移到可互動的物品上會發出金色外框，旁邊顯示名稱（可在設定關閉）。
- 對話：點一下／空白鍵／Enter 繼續；選項可用數字鍵 1、2、3。
- **Esc** 立刻中斷目前的互動並關閉所有視窗。

### 資料存放位置

- 相片：遊戲資料夾旁的 `Photos` 資料夾（編輯器裡是專案根目錄的 `Photos`），放 PNG／JPG 即可。沒有相片時會顯示三張畫好的示範風景。
- 占卜紀錄：`%USERPROFILE%\AppData\LocalLow\DefaultCompany\3D伴生範例\CompanionRoom\tarot_records.json`（最多保留 200 筆）。
- 設定、燈的開關、時段、相片位置：PlayerPrefs。

### 自動測試

在專案資料夾的 PowerShell 執行：

```powershell
& ".\Builds\CompanionRoom\CompanionRoom.exe" -roomSelfTest "D:\RoomTest" -screen-width 1600 -screen-height 900 -screen-fullscreen 0
```

會自動點過所有物品、每一步截圖，最後寫出 `report.txt`。測試用的占卜紀錄存在測試資料夾，不會動到真正的紀錄。

## 2. 模型套用規格（交給 GPT）

### 2.1 共通規則

1. **單位**：1 = 1 公尺，Y 軸朝上。FBX 匯入後尺寸要符合 2.3 節的大小。
2. **材質**：使用 URP（Universal Render Pipeline/Lit 或其他 URP 相容 shader）。不要用 Built-in 的 Standard shader（會變成粉紅色）。
3. **匯入設定**：建議勾選 Read/Write，滑鼠移入時的外框會比較平滑（不勾也能用）。
4. **階層規則（最重要）**：每個物品都長這樣

   ```
   Item_Photo              ← 掛著互動元件與 BoxCollider，不要刪、不要改名
   ├─ Model                ← 新模型放在這裡面
   │  └─ Placeholder       ← 占位模型：放好新模型後刪除或停用
   ├─ FocusPoint           ← 鏡頭拉近時看的點，可以移動
   └─（燈光、光暈、天空卡片等其他子物件：保留）
   ```

   步驟：把新模型拖進 `Model` → 對齊位置 → 刪掉（或停用）`Model/Placeholder` → 在物品根物件的元件右上角 ⋮ 選「**重新計算點擊範圍 (Fit Collider)**」。每次開始遊戲時也會自動重新計算。
5. **方位**：
   - 後牆內側在 z = 2.06，掛在後牆上的東西**正面朝 −Z**（朝房間）。
   - 左牆內側在 x = −2.56，靠左牆的東西**正面朝 +X**。
   - 地板頂面在 y = 0。鏡頭從右前方（+X、−Z 方向）往房間看。
6. **零件命名**：有幾個物品需要特定零件，可以在 Inspector 直接指定；沒指定時，程式會在 `Model` 底下找**名稱包含**以下文字的物件（不分大小寫）：

| 物品 | 元件 | 欄位 | 自動尋找的名稱 | 用途 |
|---|---|---|---|---|
| 相片 | PhotoFrameItem | Photo Surface | `Photo` | 顯示照片的面。UV 要 0–1 鋪滿畫面區域；`Surface Aspect` 填這個面的寬÷高。 |
| 電腦 | ComputerItem | Screen | `Screen` | 螢幕面，開啟設定時會發光。材質需支援 Emission（URP Lit 可以）。 |
| 壁燈 | WallLampItem | Glow Parts | `Bulb`、`Shade` | 開燈時發光的燈泡／燈罩。 |
| 櫃子 | RecordCabinetItem | Door | `Door` | 櫃門的**轉軸**（pivot 要在門的鉸鏈邊），打開時依 `Open Angles` 旋轉（預設 Y −95°）。沒有門也可以。 |

7. 不要改名、不要刪除：`Model`、`FocusPoint`、`LampLight`、`Halo`、`Sky`、`ScreenLight`，以及物品根物件上的元件。

### 2.2 各物品放置位置（物品根物件的世界座標）

| 物品 | 根物件 | 位置 (x, y, z) | 說明 |
|---|---|---|---|
| 窗戶 | `Items/Item_Window` | (−2.56, 0, 0.2) | 左牆上的窗洞：z −0.45～0.85、y 0.95～2.15（寬 1.3、高 1.2）。窗框、窗簾放 `Model`；窗外天空是 `Sky`（保留）。 |
| 塔羅 | `Items/Item_Tarot` | (−2.22, 0.745, 0.22) | 根物件在**窗下書桌的桌面**上。桌布、牌堆、水晶球等放 `Model`。 |
| 相片 | `Items/Item_Photo` | (−0.95, 2.1, 2.038) | 掛在床頭上方的後牆。 |
| 壁燈 | `Items/Item_WallLamp` | (0.05, 1.62, 2.06) | 後牆上，床頭櫃上方。`LampLight` 在燈前 0.34 m。 |
| 電腦 | `Items/Item_Computer` | (1.4, 0.75, 1.84) | 根物件在**電腦桌桌面**上；螢幕、鍵盤、滑鼠放 `Model`。 |
| 櫃子 | `Items/Item_Cabinet` | (−2.30, 0, −1.42) | 背靠左牆、正面朝 +X。 |

不可互動的家具（床、書桌、電腦桌、椅子、植物、地毯、牆、地板）都在 `Room/Shell` 與 `Room/Decor` 底下，可以整組換掉。換掉牆壁時，**左牆要保留窗洞**，陽光才照得進來。

### 2.3 建議尺寸（占位模型的大小，寬 × 高 × 深，公尺）

| 物品 | 尺寸 |
|---|---|
| 相框 | 0.64 × 0.47 × 0.045（畫面 0.52 × 0.37） |
| 電腦 | 螢幕 0.84 × 0.52，含支架高約 0.8；鍵盤 0.48 × 0.15 |
| 壁燈 | 約 0.2 × 0.3 × 0.25（離牆） |
| 窗戶 | 窗洞 1.3 × 1.2；窗台高 0.95 |
| 塔羅（桌面上） | 桌布 0.48 × 0.72；牌約 0.075 × 0.115 |
| 櫃子 | 深 0.5 × 高 1.32 × 寬 0.9 |
| 房間 | 地板 5.4 × 4.4；牆高 2.7 |

### 2.4 介面美術（RoomUISkin.asset）

所有介面元件都在 `Assets/CompanionRoom/Settings/RoomUISkin.asset`。空白的欄位會由程式畫出占位圖，所以可以一張一張換。九宮格圖片要在 Sprite Editor 設定邊界（Border）。

| 欄位 | 用途 | 建議 |
|---|---|---|
| Dialogue Box | 對話框底 | 九宮格，邊界約 30 |
| Name Plate | 對話框名牌 | 九宮格 |
| Panel / Title Plate | 相簿、設定、紀錄的視窗框與標題牌 | 九宮格 |
| Button / Accent Button / Round Button | 按鈕（一般、強調、圓形） | 九宮格／圓形 |
| Slider Track / Fill / Knob、Check Box / Check Mark | 設定頁的滑桿、勾選框 | |
| Card Back / Card Face | 塔羅牌背與牌面底 | 牌的比例約 0.61（例：512×840） |
| Font | 字型 | 預設霞鶩文楷 TC（OFL 授權，`Resources/CompanionRoom/Fonts/`） |

塔羅牌面圖：放在 `Assets/CompanionRoom/Resources/CompanionRoom/Tarot/Cards/<id>.png`（Texture Type 設為 Sprite），有圖的牌就不再顯示文字占位。id 一覽：

`fool` `magician` `high_priestess` `empress` `emperor` `hierophant` `lovers` `chariot` `strength` `hermit` `wheel_of_fortune` `justice` `hanged_man` `death` `temperance` `devil` `tower` `star` `moon` `sun` `judgement` `world`

### 2.5 音效（CompanionRoomApp 物件上的 RoomAudio）

Music、Click、Light Switch、Card Flip、Card Shuffle、Reveal、Panel Open、Panel Close。空白的會用程式合成的占位音。

### 2.6 文字內容

- 對話文字：`Assets/CompanionRoom/Resources/CompanionRoom/Dialogue/room_lines.json`。每個主題（key）有多組台詞，每次隨機挑一組、不連續重複。有 `{0}` 的是模板，請保留。
- 塔羅牌義：`Assets/CompanionRoom/Resources/CompanionRoom/Tarot/tarot_cards.json`（22 張大阿爾克那，正位／逆位各有關鍵字、牌義、建議）。要加小阿爾克那，照同樣格式往後加即可。

### 2.7 套用完成後的檢查

1. Tools → 兔兔房間 → 4. 檢查場景，Console 顯示 `RESULT: OK`。
2. 進入 Play，滑鼠移過每個物品，確認外框包住整個模型；點擊後鏡頭拉近的位置合理（不合適就移動 `FocusPoint`）。
3. 窗戶切到夜晚、打開壁燈，確認燈光位置（移動 `LampLight`）。
4. Tools → 兔兔房間 → 2. 輸出 Windows 版，再用第 1 節的自動測試跑一次，看 `report.txt` 是否為 PASS。

## 3. 可直接貼給 GPT 的摘要

> 這是 Unity 6（URP）專案 `D:\UNITY\3D伴生範例`，場景 `Assets/CompanionRoom/Scenes/CompanionRoom.unity`。請把我提供的模型套用到房間裡，**不要修改程式碼**：
> 1. 每個可互動物品在 `Items/` 底下（Item_Photo、Item_Computer、Item_WallLamp、Item_Window、Item_Tarot、Item_Cabinet）。新模型放進各自的 `Model` 子物件，對齊後刪除 `Model/Placeholder`，再對根物件執行元件選單「重新計算點擊範圍」。
> 2. 單位為公尺、Y 朝上；後牆物件正面朝 −Z、左牆物件正面朝 +X。尺寸與位置照說明文件 2.2、2.3 節。
> 3. 材質一律用 URP Lit。相框的照片面命名含 `Photo`（UV 0–1），電腦螢幕命名含 `Screen`，壁燈發光部分命名含 `Bulb` 或 `Shade`，櫃門轉軸命名 `Door`（pivot 在鉸鏈邊）。
> 4. 不要刪除或改名 `Model`、`FocusPoint`、`LampLight`、`Halo`、`Sky`、`ScreenLight` 以及物品根物件上的元件；換完不要再執行「建立範例場景」（會覆蓋）。
> 5. 完成後執行 Tools → 兔兔房間 → 4. 檢查場景，確認 `RESULT: OK`。
