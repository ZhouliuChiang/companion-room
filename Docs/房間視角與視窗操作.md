# 房間視角與視窗操作

- 滑鼠在房間內移動時，視角平滑轉動：左右最多約 3 度，上下最多約 1.5 度。
- 滑鼠離開視窗、視窗失去焦點或開啟物件面板時，視角平滑回穩。
- Windows 視窗模式：按住房間內側邊框（12 像素範圍）拖曳，可移動整個視窗，支援跨螢幕。
- 拖曳四角的粉色角框（30 × 30 像素範圍）可放大、縮小視窗。
- 邊框操作不觸發房間物件；Windows 原有標題列與視窗控制仍可使用。
- 全螢幕不顯示拖曳框；從電腦設定取消「全螢幕」後可操作。
- Unity Game 視窗可預覽滑鼠視角；桌面移動與縮放適用 Windows 執行檔。

驗證：已使用專案參考組件編譯 Windows 分支，無編譯錯誤。完整 Unity 建置在進入建置前以代碼 1 結束，參見 Logs/window-controls-build.log；Builds 內既有執行檔尚未更新。尚未完成桌面拖曳實測。
