# 新模型擺放工作區

場景：`Assets/CompanionRoom/Scenes/CompanionRoom.unity`

這次提供的 12 個模型位於 `Assets/CompanionRoom/Art/UserModels`，可直接拖曳的預製物件位於 `Assets/CompanionRoom/Prefabs/UserModels`。模型貼圖已抽出並建立 URP 材質，不依賴來源 Blender 暫存資料夾。來源 `.blend` 未修改。

## 擺放方式

1. 開啟上述場景，或使用選單「Tools → 兔兔房間 → 開啟新素材擺放場景」。
2. Hierarchy 的「房間（新模型）」是新房間。舊家具與房間占位模型已不在此場景中。
3. 展開「待擺放家具（逐件移入房間）」。家具暫存在房間外側，請逐件移動到你想要的位置。
4. 選取有中文名稱的最外層物件調整位置、旋轉或大小。底下的 `Model` 是模型本體；最外層原點位於模型底部中央。
5. 初始大小只供擺放參考，可自行調整。窗戶、壁燈和牆架也先獨立放在待擺區，沒有自動貼牆或開窗洞。
6. 擺好後按 Ctrl+S 儲存場景，再告訴我已完成，我再依你的配置調整比例、碰撞範圍、燈光並綁定互動功能。

## 功能

設定、塔羅、紀錄、日夜光線、壁燈等程式仍保留在專案內。這次僅完成新素材匯入與擺放準備，尚未把它們綁到新家具上，避免先假定家具位置與細部零件。

舊版建立房間命令在新素材模式下會開啟現有場景，避免覆蓋你的擺放。

舊版場景備份在 `Artifacts/UserModelsImport/BeforeReplacement_*`，不會載入新場景。舊原始資產仍可供還原使用。

## 素材完整性

匯入保留原模型細節，尚未進行遊戲效能用的減面。後續確定外觀後，可再製作較輕量的版本。
