# 靈擺互動

在 CompanionRoom 場景按下 Play，點擊靈擺即可使用。畫面中央直接呈現原始 3D 模型，下方沿用 RPG 對話框，選項位於右下方；沒有問題輸入框、控制面板或紀錄清單。

1. 對話「校正是」→ 點「開始校正」→ 左右擺動約 1.4 秒，自動進入下一步。
2. 對話「校正否」→ 點「開始校正」→ 前後擺動約 1.4 秒，自動進入下一步。
3. 對話「心中默念問題」→ 點「開始」→ 觀看中央吊墜擺動約 5 秒。
4. 顯示模擬結果，可選「再問一次」或「返回房間」。任何階段都可按 Esc 返回房間。

吊墜預覽背景透明，沒有方形模型視窗。模型中心對齊畫面正中央，拱架和底座固定，只讓中央吊環、鏈條、金屬帽與水晶擺動，最大角度 14 度。

模型使用完整原始網格與貼圖，透過 FixedFrame、SwingingAssembly 兩根骨骼與接點漸變權重控制擺動；沒有切除或分離任何面，因此接點不會因切割而出現裂縫。原始 Blender 檔未修改，可編輯的動畫副本為 Artifacts/Pendulum/靈擺_中央可動.blend。

這是娛樂與自我整理的模擬工具，是與否由程式等機率隨機選擇。提問只在心中默念，不輸入也不保存問題。

外觀更新：外框保留原始粉金配色並增加金屬反射；只有紫色寶石區域使用獨立透明、折射與閃光材質。Blender 副本為 Artifacts/Pendulum/靈擺_金屬紫水晶.blend，包含實際透射材質與攝影棚燈光；Unity 使用即時折射及反射近似，場景和操作畫面共用材質。

紫水晶通透與虹光更新：Unity 本體不透明度由 0.42 降為 0.18，保留邊緣與高光；虹光隨視角及擺動變化。Blender 提高透射至 1、降低體積吸收密度至 0.12，並加入 380 nm 薄膜虹光。

夜晚亮度：金屬反光、紫水晶高光與虹光現在會跟隨房間的環境光探針一起變暗，並隨早晨／夕陽／夜晚過渡平滑變化；透射的房間背景不重複壓暗。

置中操作時專用補光：透過預覽副本的渲染屬性啟用獨立柔光，清楚呈現金屬、通透水晶與虹光；共用材質及場景環境光不變，返回房間即隨預覽副本釋放。

使用畫面的展示補光已加強：暖主光與冷補光提高亮度，金屬增加柔和亮面，水晶加強內部亮度、珍珠般邊緣光與虹光；不提高水晶不透明度。效果只在預覽副本啟用，場景夜晚亮度不變。

使用時微光：展示補光改為柔和亮度，降低金屬過曝亮面；水晶加入淡紫色自發光，預覽輪廓加上輕微紫色光暈。只套用操作畫面的副本與合成材質，不改動夜晚環境或場景中的靈擺。
