# 互動說明：滑鼠外框、電腦設定、占卜手帳

場景：`Assets/CompanionRoom/Scenes/CompanionRoom.unity`

## 1. 滑鼠移到物品上

- 外框改成細的金色線（約 1.6 px，顏色不超過 1，不會被泛光放粗）。調整：`HoverOutline` 的 `width`、`color`。
- 不再顯示物品名稱，設定裡的「游標停留時顯示物品名稱」也已移除。
- 點電腦、書櫃不會跳出對話字幕，直接打開功能。

## 2. 互動怎麼綁到家具上

`Scripts/Runtime/Interaction/RoomItemBinder.cs` 有一張對照表：遊戲開始時，凡是 `assetId` 在表上的家具，會自動加上對應的互動元件。家具搬位置、換模型都不用重綁。

| 家具 | assetId | 互動 |
|---|---|---|
| 粉兔電腦 | `Computer` | `ComputerItem`：打開設定 |
| 矮書架 | `Bookcase` | `RecordCabinetItem`：拿出占卜手帳 |

想在 Inspector 調整參數時，直接在該家具最外層物件手動加上同一個元件，程式就會改用你加的那個（不會重複加）。

## 3. 占卜手帳（書櫃）

點書櫃：

1. 手帳從書櫃裡抽出來；
2. 轉成面向你、在視線高度打開封面（扉頁＋目錄）；
3. 再浮到你面前，像手帳一樣攤開。

每一則占卜是一個跨頁：

- 左頁：日期、星期、時間、時段（早晨／黃昏／夜晚）和牌陣，抽到的牌會從頁面**立起來**（立體書）。占卜時問的問題不寫在手帳上。
- 右頁：牌面筆記（位置、牌名・正逆位、關鍵字）和 MEMO 欄。
- **解讀用對話框說**：翻到一則紀錄、卡牌立起來後，對話框會跳出來逐張解讀（和桌上占卜時同一套文字：`tarot_reveal`、牌義、建議、`tarot_summary_three`），講到哪張牌，那張牌就會彈一下。點一下或按空白鍵／Enter 看下一句，說完對話框自己收起。
- 停在紀錄頁時，書會稍微上移、縮小，讓出下方對話框的位置；右下角「聽解讀」可以再聽一次。

第一個跨頁是扉頁與目錄（目錄列出日期、牌陣與時間）。

| 操作 | 作用 |
|---|---|
| 點右頁／`→`／`D`／滾輪往下／▶ | 往後翻一頁（解讀中也可以用方向鍵直接翻，會停止目前的解讀） |
| 點左頁／`←`／`A`／滾輪往上／◀ | 往前翻一頁 |
| 滑鼠停在頁面上 | 頁角會微微翹起 |
| 點書以外的地方、右上角 × | 卡牌收平 → 闔上 → 放回書櫃 |
| `Esc` | 立刻關閉 |
| 右下「刪除這則」（按兩次確認） | 刪除目前這則紀錄 |

翻頁是真的彎曲的紙頁：從頁角先掀起、捲過書脊再落下；往回翻時，左頁的立體卡牌會先收平再翻。

### 調整（在矮書架手動加 `RecordCabinetItem` 後）

| 欄位 | 作用 |
|---|---|
| Book Slot | 手帳在書櫃上的位置（書脊放在這個點，藍色 Z 軸朝書櫃外）。空白＝書櫃正面中央。 |
| Book Height | 沒有 Book Slot 時的高度，0＝模型底部，1＝頂部（預設 0.55）。 |
| Book Size | 手帳在書櫃上的頁高（公尺，預設 0.3）。 |
| Camera Focus | 拿書時鏡頭往書櫃偏移多少。自動綁定用 0.12；手動加的元件預設是 0.35，建議改成 0.1 左右（書會自己飛到面前，鏡頭不必靠近）。 |

### 程式與美術位置

- `Scripts/Runtime/Journal/RecordJournal.cs`：開書／翻頁／闔書流程、操作、對話框解讀。書由一台疊在房間鏡頭上的專用鏡頭（圖層 30）來畫，所以飛出書櫃後不會被家具擋住或穿模。
- `Scripts/Runtime/Journal/JournalBook.cs`：書本 3D 模型（封面、頁塊、彎曲翻頁、立體卡牌）。
- `Scripts/Runtime/Journal/JournalPages.cs`：封面與每一頁的版面（紙膠帶、點點方格、小兔子等都是程式畫的，之後可換成美術圖）。
- `Shaders/JournalPaper.shader`、`Resources/CompanionRoom/M_JournalPaper.mat`：書頁材質。

## 4. 桌上塔羅：不輸入問題

選好牌陣後，不再出現問題輸入框。牌堆放在桌上，對話框像 RPG 一樣問「想好問題了嗎？」，對話框右下角出現兩個虛線框選項：

- **想好了，請發牌**：開始洗牌、發牌。
- **退出**：結束這次占卜（顯示 `tarot_cancel` 的文字）。

選項操作：滑鼠移上去或 ↑↓ 移動 ▶ 游標，點擊或按空白鍵／Enter 確定，也可以按數字鍵 1、2。占卜紀錄不再存問題。

- 所有對話選項（包括選牌陣、「再占一次」）現在都是這個 RPG 樣式：`Scripts/Runtime/UI/DialogueBox.cs`，虛線底框圖是 `UISprites.DashedPanel`。
- 提問流程：`TarotDeckItem.AskReady()`；台詞：`room_lines.json` 的 `tarot_question`（最後一行是問句）。
- 桌上的塔羅牌目前還沒綁到「塔羅牌」家具上；綁上 `TarotDeckItem` 後就會走這個流程。

## 5. 自動檢查

Unity 選單 **Tools → 兔兔房間 → 檢查占卜手帳與電腦 (Play)**：自動進入 Play，滑過並點電腦、確認塔羅的「想好問題了嗎？」兩個選項都能用（另存一張含 UI 的 `tarot_ready_question_screen.png`）、打開手帳、前後翻頁、確認解讀出現在對話框、放回書櫃，每一步截圖和 `report.txt` 存到 `Artifacts/JournalCheck/`（截圖只拍 3D 畫面，對話框內容記在報告裡）。測試用的三則假紀錄放在 `Artifacts/JournalCheck/records`，不會動到真正的占卜紀錄。和其他 Play 測試同時跑會互相干擾，請一次跑一個。
